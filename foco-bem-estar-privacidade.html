Política de Privacidade

Última atualização: 23 de outubro de 2026

1. Responsável e contato

Foco & Bem-Estar é um aplicativo da Lúmen. Para dúvidas sobre privacidade, escreva para alexandreken6@gmail.com.

2. Dados que o aplicativo trata

A versão 1.0 permite registrar sessões de foco, hábitos, progresso, reflexões escritas e preferências. Essas informações ficam armazenadas localmente no aparelho do usuário pelo próprio aplicativo.

3. Coleta, compartilhamento e publicidade

A versão 1.0 não exige criação de conta, não coleta dados pessoais em servidor, não usa anúncios, não vende dados e não incorpora rastreadores de publicidade. Os dados locais não são enviados pela funcionalidade principal do aplicativo.

4. Permissões

A versão 1.0 não solicita acesso à localização, contatos, câmera, microfone, arquivos, SMS ou notificações. O aplicativo usa apenas o armazenamento local necessário para guardar as informações que o usuário registra.

5. Exclusão dos dados

Em Configurações → Apagar dados deste aparelho, o usuário pode excluir sessões, hábitos, progresso, reflexões e preferências armazenados localmente. Como a versão 1.0 não cria conta nem mantém esses dados em servidor, não há conta remota a ser encerrada.

6. Segurança e retenção

Os dados permanecem no aparelho até que o usuário os apague, desinstale o aplicativo ou limpe os dados do sistema. Recomendamos proteger o aparelho com bloqueio de tela e manter o sistema operacional atualizado.

7. Alterações nesta política

Esta política poderá ser atualizada quando houver mudanças relevantes nas funcionalidades ou no tratamento de dados. A data exibida no topo será revisada a cada alteração.
